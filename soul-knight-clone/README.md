# 元气地牢 (Soul Dungeon)

元气骑士风格的 Roguelike 地牢射击游戏。

## 快速开始

**浏览器直接打开**（推荐）：
```
直接双击 index.html 或在浏览器打开
```

**或启动本地服务器**：
```bash
cd /home/cleo/projects/soul-knight-clone
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765
```

## 操作

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 鼠标移动 | 瞄准 |
| 左键 | 射击 |
| 右键 | 技能（双持，射速翻倍 3s，CD 8s） |
| R | 换弹 |
| 1-5 | 切换武器（手枪/步枪/霰弹/激光/光剑） |
| ESC | 暂停 |
| Space | 开始 / 重新开始 |

## 游戏机制

- **3层地牢**，每层随机生成 8-14 个连通房间
- 消灭房间所有敌人后门才开启（起点房间除外）
- **护盾+血量**：受伤先扣盾，盾未受击 3 秒后自动恢复
- **5种武器**：手枪、步枪、霰弹枪、激光枪、光剑
- **3种敌人**：史莱姆（近战）、骷髅射手（远程）、蝙蝠（乱飞）
- **Boss**：每层最后有暗黑骑士，三阶段攻击模式
- **道具**：红心、能量瓶、金币
- **Buff**：速度提升、伤害翻倍（清房间概率掉落）
- 每过一层自动换新武器

## 技术

纯 HTML5 Canvas + JavaScript，单文件，零依赖。
